# Alpha Technologies

Landing page for Alpha Technologies — altitude/atmospheric water systems. Built with Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Deployment

Deploy directly to [Vercel](https://vercel.com) by importing this repository — Vercel auto-detects the Next.js configuration.

## Affiliate Links

Replace the placeholder `#cta` links in `components/systems-showcase.tsx` with your live affiliate tracking links once approved.
